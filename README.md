# מערכת כניסה לתפקיד (Role Onboarding Web Application) 🎯

מערכת מלאה ומתקדמת לניהול תהליכי כניסה לתפקיד, חניכה אישית, ספריית ידע ועץ מבנה ארגוני עם תמיכה מלאה ב-RTL, עברית ומסד נתונים ענן (PostgreSQL / Supabase).

---

## 🚀 תכונות מרכזיות (Key Features)

1. **אימות והזדהות על פי מספר אישי (7 ספרות):**
   - שדה קלט מיושר לשמאל (LTR) בתוך ממשק RTL מלא.
   - ולידציה קשיחה של 7 ספרות (`/^\d{7}$/`).
   - הזנת `0000000` מעניקה הרשאות מנהל ומפנה ישירות למרכז הניהול (`/admin`).
   - משתמש קיים מועבר מיד לדשבורד המשימות (`/dashboard`).
   - מספר אישי חדש מועבר לאשף רישום דו-שלבי (`/register`).

2. **אשף רישום דו-שלבי (`/register`):**
   - שלב 1: בחירת תפקיד יעד מתוך טבלת התפקידים הדינמית.
   - שלב 2: הזנת שם מלא, תאריך כניסה לתפקיד ותפקידים קודמים (ניהול תגיות דינמי).
   - עם סיום הרישום, המערכת מייצרת את רשומות המשימות ב-`user_task_progress`.

3. **דשבורד משימות רציף (`/dashboard`):**
   - **מנגנון נעילה עוקב (Sequential Lock):** משימה $N+1$ נעולה ולא ניתנת לביצוע עד להשלמת משימה $N$.
   - **סוגי משימות דינמיים:**
     - `simple_check`: הוראות קריאה ואישור ביצוע.
     - `media_question`: נגן וידאו / תצוגת מסמך + שאלת אימות נדרשת.
     - `text_question`: שאלת הבנה פתוחה והזנת טקסט.
   - מד התקדמות גרפי חי ואפקט קונפטי בסיום כל שלב ובסיום ההסמכה.

4. **התרמיל שלי (`/backpack`):**
   - ספריית משאבים, פקודות, נהלים, מצגות ומסמכים מחולקת לקטגוריות.
   - חיפוש מהיר וסינון לפי נושאים.
   - מודאל תצוגה מקדימה והורדת קבצים.

5. **עץ מבנה ארגוני אינטראקטיבי (`/org-tree`):**
   - תרשים עץ היררכי אינטראקטיבי עם אפשרות כיווץ והרחבת ענפים.
   - לחיצה על כל צומת פותחת Drawer מפורט:
     - מהות התפקיד ואחריות.
     - פירוט ממשקי עבודה והשפעה הדדית.

6. **מרכז ניהול מערכת (`/admin` - 0000000):**
   - **מעקב חניכים (User Progress Tracker):** טבלה לחיפוש וסינון חניכים, אחוזי השלמה, וחלונית Drill-down לצפייה בכל התשובות שהחניך הגיש.
   - **Content CMS (Full CRUD):**
     - Task Manager: יצירה, עריכה, מחיקה ושינוי סדר שלבים (`step_order`).
     - Backpack Manager: הוספה ועריכת משאבים ומסמכים.
     - Org Tree Builder: הוספה ועריכת צמתים והגדרת קשרי אב-בן וממשקים.

## 🛠️ התקנה והרצה מקומית

```bash
# התקנת תלויות
npm install

# הרצת שרת פיתוח
npm run dev

# בניית גרסת Production
npm run build
```

## 🗄️ סכמת בסיס הנתונים (Database Schema & Seed)

קובצי הסכמה והנתונים הראשוניים נמצאים בתיקיית `supabase/`:
- `supabase/schema.sql` - הגדרות טבלאות, Foreign Keys, מפתחות ייחודיים, אינדקסים ומדיניות אבטחה (RLS).
- `supabase/seed.sql` - נתוני הדגמה מלאים בעברית עבור תפקידים, משתמשים, משימות, משאבים ועץ ארגוני.
